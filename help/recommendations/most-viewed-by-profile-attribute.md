# 프로필 속성 기반 권장 사항으로 가장 많이 본 항목

이 비디오에서는 Adobe Target의 Most Viewed by Profile Attribute 기능을 사용하여 한 가지 크기의 맞춤식 인기도 목록 대신 현지화된 세그먼트별 권장 사항을 제공하는 방법을 보여 줍니다. 간단한 프로필 스크립트(필수 rexattribute\_ 접두사 사용)를 설정하고 프로필 속성 인기도 알고리즘을 선택하여 기업은 사용자 국가, 구독 계층 또는 인구 통계와 같은 속성을 기반으로 &quot;가장 많이 본&quot; 콘텐츠를 동적으로 조정할 수 있습니다.
